Formulas (auto-calculating)

Needs budget: =B2 * 50% (B2 = income cell) Wants budget: =B2 * 30% Savings budget: =B2 * 20% Spent column: =SUMIF(Expenses!C:C, "Needs", Expenses!E:E) Remaining: =Budget - Spent Status: =IF(Spent>Budget,"Over",IF(Spent>=Budget*0.8,"At Limit","On Track")) % Used: =Spent/Budget Total Spent: =SUM(Spent column) Cashflow: =Income - TotalSpent

Import from PWA

1. Open Budget Tracker PWA → Settings → Export CSV 2. Open the downloaded CSV file 3. Copy all rows (Ctrl+A → Ctrl+C) 4. Paste into this Expenses tab starting at A2 5. Dashboard, Yearly, and Goals tabs all update automatically

Tab 5 — Setup Guide

Getting Started

1. Enter your Monthly Income on the Dashboard tab (cell B2)

2. Add expenses on the Expenses tab or import from the PWA

3. Customize categories — edit the Category column, formulas auto-adjust

4. Set savings goals on the Goals tab

5. Use the Yearly tab to track month-over-month progress
